# Contributing / Mitwirken / Участие / Contribuer / 参与贡献

## Deutsch

- Fehler und Verbesserungen bitte über GitHub **Issues** melden (mit
  Beispiel-PDF, sofern möglich – **keine personenbezogenen Daten**!)
- Pull Requests sind willkommen: Beschreibung, reproduzierbare Schritte
  und Tests gehören dazu
- Alle Tests müssen grün sein: `python -m pytest tests/ -q`
- Neue Erkennungsregeln bitte immer mit einem reproduzierbaren Test in
  `tests/` absichern (Struktur-Nachbauten statt echter Dokumente)
- Dokumentation ist fünfsprachig (DE/EN/RU/FR/ZH) – neue Inhalte bitte
  in allen fünf README-Dateien pflegen
- Keine Cloud-, Abo- oder Telemetrie-Funktionen – alles bleibt lokal

## English

- Please report bugs and improvements via GitHub **issues** (with an
  example PDF if possible – **no personal data!**)
- Pull requests are welcome: include a description, reproducible steps
  and tests
- All tests must pass: `python -m pytest tests/ -q`
- Please back every new detection rule with a reproducible test in
  `tests/` (synthetic reproductions instead of real documents)
- The documentation is multilingual (DE/EN/RU/FR/ZH) – please maintain
  new content in all five README files
- No cloud, subscription or telemetry features – everything stays local

## Русский

- О багах и улучшениях сообщайте через **Issues** на GitHub (по
  возможности с примером PDF — **без персональных данных!**)
- Pull requests приветствуются: добавьте описание, воспроизводимые шаги
  и тесты
- Все тесты должны проходить: `python -m pytest tests/ -q`
- Каждое новое правило распознавания сопровождайте воспроизводимым
  тестом в `tests/` (синтетические макеты вместо реальных документов)
- Документация пятиязычна (DE/EN/RU/FR/ZH) — новые материалы вносите
  во все пять файлов README
- Никаких облачных функций, подписок и телеметрии — всё остаётся
  локальным

## Français

- Accompagnez chaque nouvelle règle de détection d'un test

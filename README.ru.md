## Что такое DocumentAI?

DocumentAI — это настольное приложение для работы с PDF-документами: оно
**анализирует** документы, **автоматически распознаёт поля форм**,
**заполняет формы**, предоставляет **более 40 инструментов** для
комментирования и редактирования, **сравнивает** версии, **экспортирует**
в форматы Office и хранит данные профилей в **локально зашифрованном
хранилище** — всё без облака, без учётной записи и без телеметрии.

Набор инструментов ориентирован на функциональность **Adobe Acrobat
Reader DC (Professional)** — полностью локально и офлайн, без подписки и
без лицензионного ключа.

## Возможности

### Распознавание полей форм
- **Модель «пара строк»**: подпись сверху, линия ввода снизу — вводимый
  текст попадает **точно на линию**, как при рукописном заполнении
- Таблицы и сетки: пустые ячейки становятся полями; заголовки столбцов
  (например, дни недели) становятся флажками с понятными подписями
- Определение типов: дата, телефон, эл. почта, почтовый индекс, IBAN,
  подпись, число, текст
- Флажки распознаются по нарисованным квадратам и глифам
- Распознанные поля при необходимости можно **перемещать мышью**

### Инструменты (45)
Выделение, панорамирование, вставка текстового поля, крестик/галочка/
точка, обводка, выделение маркером, подчёркивание, зачёркивание,
наклейка, вложение файла, рисование от руки, линия, стрелка, круг,
прямоугольник, многоугольник, соединённые линии, облачко с текстом,
текстовая выноска, измерение объектов, вставка текста, вставка
изображения, ссылка, водяной знак, колонтитулы, нумерация Бейтса,
цвет фона, замазывание (редактирование), защищённое сохранение,
подпись, заверенная копия, управление страницами (удаление, поворот,
перемещение, объединение), конвертация (Word, Excel, PowerPoint, текст,
RTF), печать, штамп, распознавание полей, удаление поля, перемещение
поля, рамка выделения — каждый инструмент со **своим значком** и
пояснением в строке состояния.

### OCR
Сканы читаются с помощью **Tesseract** (deu+eng). Предварительная
обработка (оттенки серого, увеличение в 2 раза, автоконтраст) улучшает
распознавание мелких подписей; анализ структуры скана находит линии
полей и квадраты даже без текстового слоя.

### Данные и конфиденциальность
- **Автозаполнение** из данных профилей (члены семьи) с указанием
  достоверности и валидацией
- **Хранилище данных**: локальное шифрование (AES-256-GCM), мастер-пароль
  при необходимости хранится в Windows Keyring
- **Управление версиями**: «Сохранить новую версию», отмена/повтор,
  сравнение версий (различия текста, полей, визуальное сравнение в
  виде изображения)
- **Экспорт**: Word (.docx), Excel (.xlsx), PowerPoint (.pptx), текст, RTF
- **Полностью локально**: ни облака, ни сетевого подключения, содержимое
  документов не покидает ваш компьютер

### Интерфейс
- Макет в стиле Acrobat: панель инструментов, миниатюры страниц,
  навигация, панель свойств
- **Светлая и тёмная темы** (переключатель; выбор сохраняется)
- Прокрутка колёсиком мыши, масштаб, редактирование на месте (клик по
  полю, Esc завершает)

## Установка (Windows)

1. Скачайте архив `DocumentAI-Installer_…_v18_1.9.1.zip` со
   [страницы релизов](../../releases)
2. Распакуйте его (правый клик → «Извлечь всё»)
3. Дважды щёлкните `DocumentAI-installieren.bat`

Это всё. Установка включает собственную среду Python и все библиотеки —
**без прав администратора, без подключения к интернету**. Старые
установки и ярлыки очищаются автоматически (пользовательские данные
сохраняются).

## Установка из исходного кода

Требования: Python 3.10+ (тестировалось: 3.12); Tesseract опционально
для OCR.

```bash
pip install -r requirements.txt
python DocumentAI.py            # графический интерфейс
python DocumentAI.py --cli …    # командная строка
python DocumentAI.py --selbsttest
```

Для OCR дополнительно установите бинарник Tesseract (Windows: сборка
UB-Mannheim; Debian/Ubuntu: `tesseract-ocr tesseract-ocr-deu`). Без
Tesseract всё остальное работает нормально — OCR отключается корректно
с понятным сообщением.

## Архитектура

| Модуль | Назначение |
|---|---|
| `documentai/engines/field_detector.py` | Визуальное распознавание полей форм (пары строк, сетки, полосы, промежутки, квадраты) |
| `documentai/engines/semantic.py` | Определение типов и канонических имён (немецкие составные слова) |
| `documentai/engines/ocr.py` | Интеграция Tesseract с предобработкой |
| `documentai/engines/annotate.py` | Аннотации (маркер, рисование, штампы, замазывание …) |
| `documentai/engines/exporter.py` | Экспорт/импорт (docx, xlsx, pptx, txt, rtf) |
| `documentai/engines/compare.py` | Сравнение текста, полей и визуальное |
| `documentai/engines/signatures.py` | Анализ подписей, подписание (pyhanko) |
| `documentai/services/` | Сервис анализа, профили, хранилище, поиск инструментов |
| `documentai/gui/` | Интерфейс tkinter, темы (светлая/тёмная), панели |
| `documentai/bilder/symbole.py` | Локально отрисованные значки инструментов |
| `tests/` | 249 тестов (распознавание полей, GUI, конвейер, экспорт, хранилище …) |

## Тесты

```bash
python -m pytest tests/ -q
```

- **249 тестов на хосте** (модульные + GUI под Xvfb)
- **Windows-лаборатория**: полный набор тестов под Wine
- **Проверка чистой установки**: установщик → установка →
  дымовой тест → GUI-тест, полностью автоматически

## Самостоятельная сборка установщика

Установщик для Windows собирается на Linux с помощью Wine:

```bash
bash winenv/rebuild-windows-lab.sh   # развернуть Wine-лабораторию
bash winenv/build-installer-v5.sh    # собрать ZIP установщика
bash winenv/verify-windows.sh        # проверить установку
```
